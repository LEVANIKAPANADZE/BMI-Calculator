# 🧮 BMI Calculator

A modern and responsive **BMI (Body Mass Index) Calculator** built with **Next.js**, **React**, **TypeScript**, and **Tailwind CSS**.

The application allows users to calculate their BMI, visualize where they fall on the BMI scale, browse health tips, and switch between light and dark themes.

---

## ✨ Features

- 📏 BMI calculation using height and weight
- 📊 Interactive BMI scale visualization
- 💡 Health tips loaded through a custom API route
- 🌙 Light / Dark mode with **next-themes**
- 📱 Fully responsive design
- ✅ Form validation and error handling
- ⚡ Fast performance with Next.js App Router

---

## 🛠️ Built With

- **Next.js 16**
- **React 19**
- **TypeScript**
- **Tailwind CSS v4**
- **next-themes**

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/LEVANIKAPANADZE/BMI-Calculator
```

Navigate into the project:

```bash
cd bmi-calculator
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open:

```
http://localhost:3000
```
